# 対話モードの選択・途中変更：検討案と確認事項

既存の機能設計レビューの補足。段階全体の承認や次段階への移行は行わない。

## 今回の要望

- 患者が対話モードを選択できる。
- 対話の途中でもモードを変更できる。

以下の名称・時間・変更動作は提案であり、未確定。外部AI・個人情報の保留メモの採用や、既存のAI回数上限案の変更を意味しない。

## 検討の進め方

- [x] 既存の画面仕様と対話に関する未確定事項を確認。
- [x] モードと途中変更の具体案・確認事項を作成。
- [ ] 回答を確認し、選択肢間の不整合と曖昧な点を解消。
- [ ] 合意内容を要件・ストーリー・機能設計の関連箇所へ反映し、変更範囲を報告。

## 共通動作の提案

- 開始前に各モードの目安と質問の詳しさを説明し、対話中も現在のモードと変更操作を表示する。
- 時間は患者の入力速度や回答内容で変わる目安とし、時間切れによる自動終了や入力の打切りには使わない。
- モード変更で、それまでの回答・入力中の文章・保存済み内容を消さず、最初からやり直させない。
- 短いモードへの変更は、回答済み内容を使って残りの追加質問を減らす。長いモードへの変更は、回答済み事項を重複して聞かず、必要な追加質問から続ける。
- モード変更だけで既存の確認済み内容を変更・失効させない。内容の編集・作り直しが生じる場合は、既存の版管理・本人確認の規則を適用する。
- AI応答の生成中に変更された場合、進行中の要求は開始時のモードで扱い、変更後のモードは次の要求から適用する案。画面に適用時点を示し、変更だけを理由とした追加生成は行わない。
- 短いモードでも、必要な本人確認や既存の完了条件を省略しない。短いモードは成果物の品質を下げる選択ではなく、任意の深掘りを減らす選択とする。
