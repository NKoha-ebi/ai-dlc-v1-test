# 費用試算と実現性

2026-11-05の公式情報に基づく比較案。見積り前提はレビュー対象。無料枠・割引・為替による達成を前提にしない。税・人件費・開発費は除外。円換算に用いる1 USD＝150円は比較用仮定であり当日の為替相場ではない。

## AIの試算

月間相談数は10人／日×5件×30日＝1,500件。以下の呼出回数とトークン数は未実測の低・中・高シナリオで、採用上限ではない。入力には注意事項・指示・確認済み情報・直近会話も含む。出力は課金対象の推論トークンも含めて実測し直す。キャッシュ割引・Batch・外部ツールは計算に入れない。

| シナリオ | 呼出／相談 | 月間呼出 | 入力／出力トークン毎回 | GPT-5.4 miniのUSD／月 | 仮定円換算 |
| --- | --- | --- | --- | --- | --- |
| 低 | 5 | 7,500 | 4,000／1,000 | 56.25 | 約8,438円 |
| 中 | 15 | 22,500 | 8,000／2,000 | 337.50 | 50,625円 |
| 高 | 30 | 45,000 | 16,000／4,000 | 1,350.00 | 202,500円 |

式：月間呼出×（入力トークン×0.75＋出力トークン×4.50）÷1,000,000。単価は100万トークンあたりUSD。[公式モデル仕様・価格](https://developers.openai.com/api/docs/models/gpt-5.4-mini)。実際の再試行・失敗課金・既存相談の再開・合成試験は加算。注意事項を含む入力が仮値を超えれば費用も増える。

価格比較で調査したGPT-5.4 nanoは入力0.20・出力1.25 USD／100万トークンだが、Deprecated表示のため新規採用候補から除外する。[公式仕様](https://developers.openai.com/api/docs/models/gpt-5.4-nano)。GPT-5 miniもDeprecated表示のため価格だけを理由に推奨しない。第一候補の品質・時間・予算が成立しなければ提供中の別候補を再調査する。

## 実行基盤の試算例

Cloud Runのリクエスト課金・Tier 1の公開単価例としてCPU 0.000024 USD／vCPU秒、メモリー0.0000025 USD／GiB秒、100万要求0.40 USDを用いる。1 vCPU・0.5 GiB、1呼出を直列10秒として、中シナリオ22,500呼出のAI経路は約5.69 USD／月。全呼出が60秒なら約34.10 USD。これは単純な活動時間の比較であり実サービス全体の請求額ではない。[Cloud Run価格](https://cloud.google.com/run/pricing)。

通常API・PDF・起動時間・最低インスタンスの待機時間・予備環境・ネットワーク・ビルド・イメージ保存を別に加える。同時実行による共有や日本の対象SKU・実構成を反映して価格計算機で再見積りする。最小台数0の案と常時待機案ではコールドスタートと費用が変わる。地域選択前に本番総額を確定しない。

## 月額項目と未確定額

| 項目 | 見積り入力・現状 |
| --- | --- |
| OpenAI | 上表56.25〜1,350 USD。中337.50 USDは利用仮定で大きく変動 |
| 主系実行 | AI経路のみ上記約5.69〜34.10 USDの例。通常API・PDF等を加算 |
| DB読書き | 相談ごとの読取・書込・索引読取・一覧・再開・運営操作を実測。回数未確定のため総額未算出 |
| DB保存 | 相談は退会まで蓄積。仮に100 KiB／相談なら半年9,000件で本文等約0.86 GiB。索引・版・改善コピー・操作ログは別。1 MiB／相談なら約8.6 GiB |
| PITR・バックアップ・復元 | 保存量と保持日数、復元試験頻度で算出。PITR・バックアップは無料枠内とは扱わない |
| 認証・メール | 登録100人だけで課金額を断定しない。認証製品・追加認証・重要通知件数・配信基盤を確定後算出 |
| 配信・ネットワーク | SPA／PDF転送量、地域間複製、外部API通信を加算 |
| ログ・監視・秘密 | 本文なしイベント件数、保持180日等の対象ごとの期限、監視頻度で算出 |
| Pilot Light | 待機先のDB保護・複製・実行・切替・復旧試験費用。地域トポロジー未選択につき未算出 |
| 試験・予備費 | 合成評価・負荷・復旧試験、失敗再試行・為替・増加分を別枠化 |

参考：[Firebase料金](https://firebase.google.com/pricing)、[Firestore料金](https://cloud.google.com/firestore/pricing)。無料枠は製品・課金アカウント・利用日単位等の条件があるため、初期試算はゼロ円保証に利用しない。Blaze等の課金有効化は本作業では行わない。

現時点の確定可能な比較はAI費用と実行経路の一部。復旧目標を満たす総額は未確定であり「数千円で全条件を達成」とはしない。次段階の構成選択後に全項目を積み上げて月額上限を承認する。AI費用だけでも中シナリオ約5万円／月となる点を予算レビューの論点とする。

## 目標との両立条件

| 条件 | 現状と必要な確認 |
| --- | --- |
| RTO10分・24時間 | 人手対応は平日日中。自動化・時間外対応または承認された目標変更が必要 |
| RPO10分・Pilot Light | 日次バックアップのみでは不足。PITRと地域障害対策を分け、待機データ保護を選択 |
| 削除35日以内 | 主要削除7日以内＋バックアップ保持28日案を候補にし、復元・再コピー・期限処理を含め検証 |
| OpenAI保持 | store=falseだけでは監視保持は消えない。外部保持条件と説明／契約を確認するまで実データ有効化なし |
| AI60秒 | モデル名・トークン予算・同時呼出・クォータが未確定。合成データでp95・上限・成否不明処理を検証 |

以上は要件の勝手な変更ではなく、非機能設計・インフラ設計に渡す成立条件。元の目標を維持し、実測で両立しない場合は根拠と変更案を提示する。
