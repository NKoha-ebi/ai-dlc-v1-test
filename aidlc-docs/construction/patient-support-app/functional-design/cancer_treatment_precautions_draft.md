# がん種×治療時期×治療内容：AI応答の注意点（確認用ドラフト）

## 共通事項

すべての組み合わせに本節と該当する条件別共通事項を適用し、その上で、がん種別共通事項・個別項目を参照する。症状や悩みがあると仮定せず、本人の相談に関係する内容だけを応答に反映する。

- 病期、予後、治療目的、具体的な病名・薬剤・術式・照射部位、症状や生活への影響を、選択された属性だけから推測しない。
- 症状を副作用、再発、心理的要因と断定しない。症状がないことから検査上の異常もないと判断しない。
- 薬の開始・中止・増減、治療の変更を指示しない。サプリメント等の追加も安易に勧めない。
- 食事、飲水、運動、入浴、復学・復職、運転などの個別の可否や時期を一律に指示せず、医療者の個別指示を優先する。
- 本人の悩み・希望を優先する。性別、パートナー、妊娠・出産の希望、喪失感を決めつけず、必要な場合だけ話す意向を確認する。
- 治療名・時期が不明でも会話を続ける。「回答しない」を尊重し、繰り返し開示を求めない。
- 急な呼吸困難、意識の変化、止まらない出血、飲食できない状態など、強い症状や急変では速やかな医療機関への連絡を促す。生命に関わる急変では救急対応を優先する。
- 薬物療法中の発熱・悪寒などを軽視しない。治療施設の連絡基準を優先し、数値や治療名が不明でも連絡を妨げない。定期受診まで待つよう一律に勧めない。
- 複数治療では各項目を併用するが、同時実施と推定しない。一般的でない組み合わせも入力誤りや不適切な治療と判断しない。
- 治療中以外の「未取得」は、治療歴がないことを意味しない。予定・過去の治療は相談に必要な場合のみ確認する。

| 治療時期：治療中／治療内容：化学放射線治療 | 使用薬と照射部位の両方が不明なまま副作用を特定しない。食事、体力、通院の負担が重なる場合にも、我慢を促さない。 |
| 治療時期：治療中／治療内容：放射線治療 | 照射部位は原発部位とは限らない。治療終了後に影響が出る場合もあるため、終了すれば直ちに回復すると保証しない。 |
| 治療時期：治療中／治療内容：その他 | 治療名を答えることを会話継続の条件にしない。必要な場合だけ、相談内容に関係する処置、薬、生活上の指示を確認する。 |
| 治療時期：治療中／治療内容：不明 | 治療名が分からなくても会話を続ける。薬の色や外見から薬剤を推定したり、症状から治療内容を逆算したりしない。 |
| 治療時期：治療中／治療内容：不明 | 相談に必要な場合だけ、本人の分かる言葉で治療や医療者からの指示を確認する。特定治療の副作用説明や生活制限を当てはめない。 |
| 治療時期：治療中／治療内容：回答しない | 治療内容を話さない意向を尊重し、別の聞き方で繰り返し回答を求めない。症状や他の発言から治療名を補完しない。 |
| 治療時期：治療中／治療内容：回答しない | 話してもらえた悩み、希望、身体の状態だけを用いて応答し、特定治療の副作用や生活制限を当てはめない。 |
| 治療時期：治療後 | 治療の終了を完治、無症状、服薬の終了と同一視しない。予定・過去の治療は、相談に必要になった場合のみ確認する。 |
| 治療時期：経過観察 | 治療後の定期検査、治療開始前の観察などを選択だけで区別しない。無治療、完治、病状が軽いことを意味すると説明しない。 |
| 治療時期：経過観察 | 検査や結果待ちの不安が語られた場合は、その時点で本人が必要としている支えを扱う。検査間隔や再発確率を推定しない。 |
| 治療時期：その他 | 治療の休止、切り替え、再発後、がんに対する治療を受けていない状況などのいずれかと推測しない。終末期や治療の断念と同一視しない。 |
| 治療時期：その他 | 必要な場合だけ、今受けている支援やこれからの予定を確認する。症状を和らげる医療や支援は、がん治療の有無だけで不要としない。 |
| 治療時期：不明 | 治療時期が分からないことを問題視しない。治療前・治療中・治療後を文章や症状から推定しない。 |
| 治療時期：不明 | 応答が変わる場合だけ、最近受けた治療や現在の医療者からの指示を、答えられる範囲で確認する。時期に依存する指導を避ける。 |
| 治療時期：回答しない | 治療時期を話さない意向を尊重する。同じ情報を別の言い方で求めたり、開示を会話継続の条件にしたりしない。 |
| 治療時期：回答しない | 治療経過に沿った回復の見通し、生活制限、予後を提示しない。本人が話したい悩みや希望を優先する。 |

### 殺細胞性抗がん剤（細胞障害性抗がん薬）：代表的な副作用と時期

**適用条件：** 細胞障害性抗がん薬の使用が確認できた場合。化学放射線治療で同薬を使用している場合も参照する。

**時期は一般的な目安であり、薬剤・用量・併用薬・投与間隔・支持療法・個人の状態で異なる。** 以下は主に間欠投与を想定した目安で、連日内服や週ごとの投与では同じ時間経過にならない。すべての副作用が起こるとは限らず、表の時期以外に起こることもある。

| 代表的な副作用 | 出現時期・経過の目安 | AI応答で留意すること |
|---|---|---|
| アレルギー反応 | 投与中～投与直後。初回だけでなく、繰り返し投与後にも起こり得る。 | 発疹、息苦しさなどが投与中に出た場合は、その場の医療者に直ちに知らせるよう促す。投与回数から安全と判断しない。 |
| 吐き気・嘔吐 | 当日～24時間以内の急性のものと、24時間以降～数日間の遅発性のものがある。多くは5日～1週間程度で軽減するが、個人差がある。 | 投与直後に症状がなくても、その後の発症を否定しない。飲水できない、強い嘔吐が続く場合は医療機関への連絡を促す。 |
| 食欲低下・倦怠感 | 投与後早期～1、2週間ごろにみられることがある。治療の反復や併存する症状により続く場合もある。 | 気力や努力の問題としない。貧血、感染、脱水など別の原因もあり得るため、副作用と断定しない。 |
| 口内炎 | 投与後数日～1、2週間ごろに出ることがある。 | 痛み、食事・飲水への影響を本人の訴えに応じて扱う。強い摂取困難や発熱を伴う場合は連絡を促す。 |
| 下痢・便秘 | 投与後早期～1、2週間など。薬剤によって直後に起こる下痢もあり、制吐薬など併用薬の影響もある。 | 発症日だけで原因を決めない。強い腹痛、嘔吐、続く下痢や脱水が疑われる場合は連絡を促す。下剤や止痢薬の自己調整を指示しない。 |
| 白血球・好中球減少 | 多くの間欠投与では7～10日ごろから減少し、10～14日ごろに最低となり、約3週間で回復することがある。レジメンにより大きく異なる。 | 自覚症状だけでは分からず、血液検査で確認する。発熱・悪寒があれば時期にかかわらず速やかな連絡を促す。「投与から3週間たったので回復した」と判断しない。 |
| 血小板減少・貧血 | 投与後の数日～数週間や、治療を重ねる中でみられる。白血球減少と同じ時期・回復経過とは限らない。 | 出血、あざ、息切れ、だるさなどを軽視しない。血球数を症状から推定せず、検査と担当医の説明を優先する。 |
| 脱毛 | 原因となる薬剤の開始後1～3週間ごろから始まることが多い。すべての薬剤で起こるわけではない。 | 外見の変化の意味を本人に代わって決めない。髪だけでなく眉毛・まつ毛などの変化も、本人が気にしている場合に扱う。 |
| 末梢神経障害（しびれ・感覚の変化など） | 数週間後や数回の投与後から出現し、累積して強まることがある。一方、オキサリプラチンでは投与直後～数日以内に寒冷刺激で誘発される症状もある。終了後も長く続く場合がある。 | 「数週間たつまでは出ない」「治療終了ですぐ治る」と説明しない。手作業、歩行、転倒など生活への影響があれば、早めに担当医療者へ伝えるよう促す。 |
| 皮膚・爪の変化 | 数週間以降や反復投与に伴って目立つことがあるが、早期の発疹などもあり、薬剤差が大きい。 | すべて同じケアで対処できるとしない。急に広がる発疹、水疱、粘膜の異常などは医療者への速やかな連絡につなぐ。 |
| 肝・腎機能などの臓器障害 | 薬剤によって早期から生じるものも、累積して現れるものもあり、一律の発現時期を設定しない。 | 自覚症状がなくても検査で見つかる場合がある。見た目の元気さや経過日数から安全と判断しない。 |

- この表は症状の原因を診断したり、副作用の有無を予測したりするために使わない。相談に関連する場合のみ、薬剤名、直近の投与日、症状の始まりと変化、医療者からの説明を必要な範囲で確認する。
- 重い症状や急変では、上記情報をそろえることより連絡・受診を優先する。「予想される時期だから様子を見てよい」と説明しない。

### 分子標的薬：代表的な副作用と時期

**適用条件：** 分子標的療法。下表の薬剤群・薬剤の使用が確認できた場合に、その行を参照する。がん種や「分子標的療法」の選択だけで薬剤を特定しない。

分子標的薬全体に共通する一つの発現スケジュールはない。開始後の日数は目安であり、薬剤、併用薬、既往歴、用量などで異なる。抗体薬物複合体（ADC）などでは細胞障害性抗がん薬に似た副作用もあり、必要に応じて前表も参照する。

| 代表的な副作用・主に該当する薬剤群 | 出現時期・経過の目安 | AI応答で留意すること |
|---|---|---|
| 投与時反応（点滴の抗体薬など） | 多くは投与開始直後～24時間以内。薬剤差があり、初回以外にも起こり得る。 | 悪寒、発熱、発疹、息苦しさなどが投与中に出たら、その場の医療者に直ちに知らせるよう促す。感染やアレルギーとの区別をAIが行わない。 |
| ざ瘡様皮疹（一部のEGFR阻害薬など） | 開始後2週間以内に現れることが多い。 | 普通のニキビと同じと説明せず、外見、痛み、かゆみ、仕事や対人場面への影響を扱う。皮疹の程度から治療効果を判断しない。 |
| 皮膚乾燥・亀裂（一部のEGFR阻害薬など） | 乾燥は開始後3～7週間ごろが目安。治療の継続中に問題となることもある。 | 手洗い、家事、手作業などへの影響を確認する。強い痛みや皮膚の傷は医療者への相談につなぐ。 |
| 手足症候群（一部のマルチキナーゼ阻害薬など） | 開始後10日以内など、早期から出る場合がある。薬剤によって異なる。 | 手のひら・足裏の痛み、歩行や物を持つ難しさを軽視しない。細胞障害性抗がん薬と同じ時期・経過を当てはめない。 |
| 下痢・口内炎（該当する一部の薬剤） | 開始後早期から起こるものも、継続中に起こるものもあり、薬剤ごとの説明を優先する。 | 便の回数・変化、腹痛、水分摂取への影響を必要な範囲で確認する。続く下痢、強い腹痛、飲水困難は速やかな連絡につなぐ。 |
| 高血圧・蛋白尿（VEGF経路を阻害する薬剤など） | 治療開始後から継続中に生じ得る。一律の発現日・回復時期を設定しない。 | 自覚症状がなくても測定・検査で分かる場合がある。家庭血圧などの記録は担当医への共有を支援し、AIが降圧薬を調整しない。 |
| 出血・消化管穿孔など（VEGF経路を阻害する一部の薬剤） | 治療期間中に起こり得るが、日数で安全性を判断できない。 | 血痰、吐血・血便、突然の強い腹痛などは速やかな医療機関への連絡を促す。薬剤が不明でも対応を遅らせない。 |
| 間質性肺炎・肺障害（該当する一部の薬剤・ADCなど） | 早期から継続中まで、薬剤により異なる。長く服用できていることから発症を否定しない。 | 新たな空咳、発熱、息切れは速やかに治療施設へ伝えるよう促す。がんの悪化、感染、薬剤の影響をAIが区別しない。 |
| 肝機能障害、血球減少、不整脈など（該当する一部の薬剤） | 発現時期は薬剤ごとに異なり、検査で初めて分かる場合もある。 | 「分子標的薬だから骨髄抑制や臓器障害はない」と説明しない。発熱、出血、動悸、失神などの訴えや、施設の連絡指示に応じてつなぐ。 |

- 薬剤が不明な場合は、この表のすべてが起こるように説明しない。症状への対応は、経過日数より重症度と変化を優先する。
- 参考：[皮膚のトラブル](https://ganjoho.jp/public/support/condition/skin/index.html)、[薬物療法の副作用](https://ganjoho.jp/public/dia_tre/treatment/drug_therapy/dt02.html)、[日本肺癌学会：分子標的治療薬の副作用](https://www.haigan.gr.jp/public/guidebook/2024/2024/Q44.html)。

### 放射線治療：代表的な副作用と時期

**適用条件：** 放射線治療、および化学放射線治療の放射線部分。下表は主に外部照射の目安であり、小線源治療・放射性医薬品による内用療法にそのまま適用しない。

副作用は、照射部位、線量、分割回数、併用治療などで異なる。急性期の影響は治療中～終了後早期、晩期の影響は終了後数カ月～数年以降にも現れ得る。治療終了後に一時的に強くなるものもあり、「終了したので副作用の心配はない」と説明しない。

| 代表的な副作用・関係する照射部位 | 出現時期・経過の目安 | AI応答で留意すること |
|---|---|---|

### ホルモン療法：代表的な副作用と時期

**適用条件：** がんに対する内分泌療法。薬剤名・作用が分かる場合に該当する行を参照する。甲状腺ホルモン補充・TSH抑制などには、下表をそのまま適用しない。

ホルモン療法には、タモキシフェン、アロマターゼ阻害薬、卵巣機能抑制、前立腺がんに対するアンドロゲン抑制などがあり、副作用は同じではない。開始直後からの日数を一律には設定できず、治療中から長期継続に伴って現れる影響を区別する。長期服用できていることを、副作用がない根拠にしない。

| 代表的な副作用・主に該当する治療 | 出現時期・経過の目安 | AI応答で留意すること |
|---|---|---|
| ほてり・のぼせ・発汗（性ホルモンの作用・分泌を抑える治療） | 開始後から治療中に現れ得る。乳がんの内分泌療法では数カ月程度で落ち着く場合があるが、長く続く人もいる。 | 「数カ月で必ず治る」とせず、睡眠、仕事、外出への影響を扱う。発熱や感染の症状をほてりだけで説明しない。 |
| 関節の痛み・こわばり（アロマターゼ阻害薬など） | 治療開始後～継続中。出現・軽快の時期には個人差があり、固定した日数を設けない。 | 手作業、家事、歩行への支障を扱う。新しい痛みを薬の影響と断定せず、担当医療者への相談につなぐ。 |
| 骨密度低下・骨折リスク（アロマターゼ阻害薬、卵巣機能抑制、アンドロゲン抑制など） | 継続に伴って問題になることがあり、症状がないまま進む場合もある。 | 「ホルモン療法はすべて骨を弱くする」と一般化しない。骨密度の確認や予防の方針は担当医に相談するよう促し、運動や補充薬を一律に勧めない。 |
| 性・生殖器の症状（治療の種類による） | 治療中に現れ、継続中や終了後にも続く場合がある。回復時期を一律に示さない。 | 腟の乾燥・性交痛、性欲の変化、勃起の困難など、本人が語った内容だけを扱う。性別、パートナー、生殖機能の状態を推測しない。 |

| 体重・代謝の変化（特にアンドロゲン抑制など） | 継続・長期治療に伴って問題になる場合がある。個別の発現時期は予測しない。 | 体重増加や糖・脂質代謝の変化を努力不足としない。検査値や既往歴に応じた管理は担当医に確認し、極端な食事制限を提案しない。 |
| 乳房の張り・痛み、乳房の増大（前立腺がんの一部の内分泌療法など） | 治療継続中に起こり得るが、薬剤や個人によって異なる。 | 外見や衣服、親密な関係への影響は本人の受け止めを優先する。男性らしさなどの価値観を持ち込まない。 |

| 不正性器出血・子宮内膜への影響（タモキシフェンなど） | 治療中に出血が起こる場合があり、一部の影響は長期服用との関連もある。一律の発現日を設定しない。 | 月経の異常や不正出血を「薬のせいだから問題ない」としない。症状があれば医療者に相談するよう促し、出血からがんを診断しない。 |
