# 各画面の配置・配色（決定版）

配置・配色の承認および確認質問1A・2Aに基づく決定版。共通配色・寸法・画面別配置、P06の質問カードと初期状態での履歴折りたたみを採用する。実画面での可読性・余白の調整は承認内容に含む。既存の必須操作・画面遷移は変更しない。正式ロゴ「header logo_背景透過.png」を目視確認し、そのピンク系の色調を基に配色を定めた。色コードはロゴからの厳密な抽出値ではない。画面配置の業務仕様は[patient-screen-layout.md](patient-screen-layout.md)、部品契約は[frontend-components.md](frontend-components.md)を参照。

## 共通の色

淡いピンクは画面の背景と選択箇所に使う。長文を読む領域は背景を白（#FFFFFF）にし、文字は濃いグレー（#29252A）で表示する。画面ごとに主操作の色を変えない。ロゴ自体の色・形状・縦横比は維持する。

| 用途 | 色 | 使用箇所 |
| --- | --- | --- |
| 全体背景 | #FFF8FA | 本文の外側。長文領域の背景は白 |
| カード・入力欄・ヘッダー | #FFFFFF | 通常の内容面 |
| 主操作・選択枠 | #A63259 | 保存・次へ・送信等。文字は白 |
| 主操作ホバー | #872545 | マウス操作時。文字は白 |
| 選択面・モード帯 | #FBE7EE | 選択した支援、現在メニュー、モード帯。文字は#29252A |
| 本文・見出し | #29252A | 長文と主要情報 |
| 補足・日時 | #665B62 | 小さく薄すぎる文字にしない |
| カードの境界 | #E3D5DC | 装飾用。操作の識別をこの線だけに頼らない |
| 入力枠 | #85717C | 白い入力面との境界。選択は濃いローズでも示す |
| エラー・削除 | #B42318 | エラー文・危険操作。削除ボタンは白地に赤文字・赤枠 |
| 通常リンク・情報 | #245B91 | 下線付きリンク、案内。背景は白 |
| 保存成功・完了 | #35634C | 白地の状態ラベル。文字と記号を併記 |

通常の主操作とエラーを同じ色にしない。状態は「途中」「確認が必要」「完了」等の文字で識別し、色だけに依存しない。無効操作は理由を近くに表示し、淡色化だけで説明しない。キーボードフォーカスは#245B91の外枠と白い隙間で示し、赤いエラー枠と区別する。

## 共通の配置・寸法

| 要素 | PC | スマートフォン |
| --- | --- | --- |
| ヘッダー | 高さ80pxを基準に内容へ追従。左からメニュー・ロゴ | 同じ順序。高さ80px基準、文字拡大で高さ可変 |
| ロゴ | 最大幅88px・最大高さ64pxの範囲へ全体を収める | 同じ。切り抜きなし。文字の可読性は実表示で確認 |
| サイドバー | 幅224px。現在項目を淡ピンク面と濃い文字で示す | 閉じた状態から開く。閉じる操作とフォーカス復帰を用意 |
| 本文 | 一般画面最大960px、入力・対話は720px、認証は440px | 左右余白16px、1列 |
| 余白 | 本文周囲32px、カード内24px、要素間16px、節間32px | 本文周囲16px、カード内16px、要素間16px |
| 文字 | 本文16px、行高1.7、画面見出し28px、補足14px以上 | 本文16px、見出し24px、補足14px以上 |
| 入力・ボタン | 高さ48px以上、ラベルは上、角丸8px | 同じ。主ボタンは基本横幅いっぱい |
| カード | 白・角丸12px・控えめな境界。影は原則なし | 同じ。横方向にはみ出させない |

本文の読み順は上から見出し→説明→入力／結果→保存状態→主操作。主操作は手順ごとに一つを目立たせる。戻る・取消・中断・省略は白地の枠付きボタンまたはリンクで区別する。主ボタンは原則本文内に置き、下部全面固定による入力欄の隠れを避ける。モード帯はヘッダー直下へ追従固定し、可変ヘッダー高と拡大表示を考慮する。

## 確認・失敗・処理中の共通表示

離脱確認は中央の白いダイアログ、狭い画面では左右16pxの余白を確保する。題名→作業／保存状態→操作の順。初期フォーカスは「整理を続ける」、保存して戻る・保存せず戻るは既存条件に応じて表示する。長い内容はダイアログ内で読めるようにし、閉じたら呼出元へフォーカスを戻す。

エラーは該当欄の近くと必要時の要約に文字で示す。成功・失敗・0件・取得中・成否不明は別の表示とする。処理中の画面全体の暗転・置換は行わず、既存の部分処理表示を使う。危険操作の確認で通常の「保存」と同じラベルを使わない。

## 検証と確定範囲

色の計算確認：白文字／主操作#A63259は6.52:1、本文#29252A／全体背景は14.41:1、補足#665B62／白は6.49:1、エラー#B42318／白は6.57:1、リンク#245B91／白は7.05:1、完了#35634C／白は6.91:1。sRGB相対輝度式で計算した代表組合せの値であり、画面全体の適合確認を意味しない。

実装後はスマホ・PC、文字拡大、キーボード、固定モード帯とヘッダー、ソフトウェアキーボード、ロゴ文字の可読性、各状態の実際の背景と文字の組合せを確認する。本書の具体寸法・配色・P06カード初期表示・履歴折りたたみは承認済み。実画面の検証は未実施。今回の承認は配置・配色を対象とし、機能設計全体の承認には拡張しない。ユーザー指示により本決定版作成後は次段階へ進まず、AIの動き方についての質問を待つ。
