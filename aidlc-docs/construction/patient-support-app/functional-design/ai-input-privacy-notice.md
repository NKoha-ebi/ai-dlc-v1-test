# AIへ送る記述欄の個人情報注意書き

2026-11-05のユーザー指示に基づく追加仕様。[プライバシーポリシー](../../../inception/requirements/privacy%20policy.txt)第4条3・4項に対応する。運営26問の追加確認と独立して採用する。

## 表示文言

「AIに送る内容には、ご自身や他の方の氏名・住所・電話番号・メールアドレスなど、個人が特定できる情報を入力しないでください。必要な場合は『家族』『職場の人』などに置き換えてください。」

補足リンク「個人情報の取り扱いについて」から、プライバシーポリシー第4条の説明へ移動できるようにする。画面内の説明または別タブ等の具体方式は実装時に揃え、入力途中の文章を失わせない。リンク先の実URLは公開先の決定後に設定する。

## 対象と位置

| 対象 | 表示位置・適用 |
| --- | --- |
| P05a 最初の悩み入力 | ラベル・短い説明の後、記述欄の直上 |
| P05b AI抽出案の編集 | 再送信され得る自由記述の編集欄群の直上に1回 |
| P06 各支援の質問回答・自由記述・手入力の編集 | 現在入力する欄または欄群の直上。全5支援・両モード・再編集時に共通適用 |
| その他の患者自由記述 | AI入力に含まれる場合に適用。別画面へ遷移しても該当欄の近くに表示 |
| アカウント登録・認証メール、問い合わせ、運営の編集欄 | AI送信を前提としないため、このAI注意書きは適用しない。認証に必要なメール入力を禁止する表示にしない |

過去の対話全件に繰り返して表示せず、現在の入力欄と結び付ける。プレースホルダーだけ、ツールチップだけ、初回だけ、折りたたみの内側だけの表示にしない。入力中・フォーカス中・エラー表示中・AI生成中にも注意文を残す。

## 表示・部品契約

- 補足文字はPC・スマートフォンとも14px以上、行高1.7を基準とし、文字拡大と折返しに対応する。
- 現行配色の補足文字#5D6966と白背景#FFFFFFを使う。小さなコーラル文字等にせず、エラーと区別する。色だけに意味を持たせない。
- 共通表示部品AiInputPrivacyNoticeをフォームが配置する。入力欄は説明要素をaria-describedby相当で参照する。初期表示の通常説明とし、毎入力・毎生成で警告を読み上げ直さない。
- 初回同意チェックや送信ごとの確認ダイアログは追加しない。注意文自体は業務状態を更新せず、入力文を勝手に変更・破棄しない。

## 処理上の境界と確認観点

注意書きは既存の送信前識別情報検出・削除／置換を代替しない。自動処理で完全に保護できるという文言は表示しない。注意文をAIへ送る相談本文・履歴・PDF・操作ログへ混入させない。

実装時は、対象欄すべてで入力前後に文言が見えること、狭い画面・文字拡大時に切れないこと、読み上げ時に入力欄の説明として参照されること、説明リンクから戻っても未送信入力が保持されることを確認する。実装・ブラウザー検証は未実施。
