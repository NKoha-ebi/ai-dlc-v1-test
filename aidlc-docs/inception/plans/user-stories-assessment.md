# ユーザーストーリー実施評価

## 評価

- [x] 利用者への影響を確認: 患者の整理支援・PDF、運営操作、研究閲覧・集計に直接影響。
- [x] 高優先の実施条件を確認: 新規ユーザー機能、複数の利用者役割、動的な支援フロー、同意・権限に関する複数シナリオ。
- [x] 効果を確認: 本人確認・同意・再開・生成結果の確認・集計抑制を受入条件として検証できる。

## 決定

ユーザーストーリーを実施する。複雑度は高。対象は患者（15〜17歳と18〜39歳の差を含む）、保護者等の同意者、運営者、研究者、集計情報の受領者。費用負担者を患者情報の閲覧者と同一視しない。

要件定義書の承認回答Aにより、この段階への移行を承認済み。ワークフロー全体の実行計画は、規定の順序に従いストーリー承認後に作成する。ここでは作成方法の計画だけを扱う。
