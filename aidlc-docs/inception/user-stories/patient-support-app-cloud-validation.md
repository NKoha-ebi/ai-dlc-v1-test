# 患者支援アプリのクラウド検証受入条件

[承認済みクラウド接続要件](../requirements/patient-support-app-cloud-integration.md)に基づく独立作業。対象は get-check-1120 のアクセス限定環境で、初回は東京を候補とし、架空のアカウントと相談のみを使用する。利用者は既存の [P1 患者ペルソナ](personas.md) に対応する試験利用者。

| ID | 操作 | 合格条件 |
| --- | --- | --- |
| CV-01 | 登録・同意・ログイン | 同意した試験アカウントが登録・再ログインでき、同意前の相談操作は拒否される。 |
| CV-02 | 相談の整理・対話・要約 | Cloud Run から OpenAI Responses API を呼び出し、整理案・対話・要約を表示できる。入力に応じた共通・該当がん種の注意事項を適用し、診断・治療判断を提示しない。 |
| CV-03 | 再ログイン・再配備後の再開 | Firestore に保存された相談、対話、まとめを同じアカウントの新しいセッションで復元できる。 |
| CV-04 | アカウント間の分離 | 別アカウントと未認証の要求では、対象相談の参照・更新・削除が拒否される。 |
| CV-05 | OpenAI または保存の失敗と再開 | 失敗が画面に表示され、最後に保存された状態から再開できる。失敗を保存成功と表示せず、再試行で確定済みの項目が重複しない。 |
| CV-06 | 退会と削除 | 完了後に既存セッションが利用できず、プロフィール・同意・相談・対話・まとめが設計上の削除条件どおり処理されたことを確認できる。 |
| CV-07 | 初回配備のアクセス・秘密管理 | 許可されたテスターが HTTPS で利用でき、OpenAI API キーがブラウザー、リポジトリ、ログに出ない。 |

RESILIENCY-03 はレビューと変更記録に反映。RESILIENCY-10 は CV-05 に反映し、実環境の判定は検証時に行う。その他の回復力規則はこの受入条件の文書差分では対象外。部分 PBT はコード生成前のため対象外。無効セキュリティ拡張は適用省略。
